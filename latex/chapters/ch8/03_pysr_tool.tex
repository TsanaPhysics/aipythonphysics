\subsection{Method: PySR and Evolutionary Search \quad / \quad \textthai{วิธีการ: PySR และการค้นหาเชิงวิวัฒนาการ}}
\begin{paracol}{2}
One of the most advanced tools for symbolic regression today is \texttt{PySR}\index{PySR@PySR (PySR)}, which combines Python's ease of use with the high-performance Julia backend. \texttt{PySR} uses evolutionary algorithms (Genetic Programming) to evolve equations over generations, selecting for survival those that best describe the physics of the system.

\switchcolumn

\begin{thai}
หนึ่งในเครื่องมือที่ก้าวหน้าที่สุดสำหรับการถดถอยเชิงสัญลักษณ์ในปัจจุบันคือ \texttt{PySR} ซึ่งรวมความง่ายในการใช้งานของ Python เข้ากับความสามารถในการประมวลผลประสิทธิภาพสูงของภาษา Julia โดย \texttt{PySR} ใช้อัลกอริทึมเชิงวิวัฒนาการ (การโปรแกรมเชิงพันธุกรรม) เพื่อพัฒนาสมการผ่านรุ่นต่างๆ โดยคัดเลือกสมการที่อธิบายฟิสิกส์ของระบบได้ดีที่สุดเพื่อให้อยู่รอด
