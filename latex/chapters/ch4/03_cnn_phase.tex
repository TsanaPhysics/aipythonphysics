\subsection{Method: CNNs for Phase Classification \quad / \quad \textthai{วิธีการ: CNN สำหรับการจำแนกสถานะ}}
\begin{paracol}{2}
In this chapter, we use Convolutional Neural Networks (CNNs) to analyze 2D spin configurations. Because spin lattices look like black-and-white images, CNNs can easily "see" the patterns of order and disorder. This approach has been extended to "Topological" insulators, where the order is not visible to the naked eye.
