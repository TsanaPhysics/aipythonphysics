Open-source & Marker-based AR

AR.js for Interactive Media

เปลี่ยนหน้ากระดาษหนังสือเรียนให้เป็นสื่อโต้ตอบ 3 มิติ ด้วยการตรวจจับรูปภาพและสัญลักษณ์พิเศษ

1. AR Periodic Table (Image Tracking)

การใช้ Image Tracking เพื่อส่องไปที่รูปผังธาตุในหนังสือ แล้วให้ระบบแสดงโครงสร้างอะตอม 3 มิติ (Bohr Model) ของธาตุนั้นๆ ลอยขึ้นมา

[ 3D Visualization Placeholder: รูปภาพธาตุ Oxygen ในหนังสือที่มีโมเดลอิเล็กตรอนวิ่งรอบนิวเคลียสซ้อนทับอยู่ ]

การตั้งค่า Image Tracking ใน AR.js

<a-scene embedded arjs="trackingMethod: best;">
  <!-- ส่องที่ภาพธาตุไฮโดรเจน (.mind หรือ .nft file) -->
  <a-nft type="nft" url="path/to/hydrogen_image">
    <a-entity id="atom_hydrogen">
      <a-sphere position="0 0 0" radius="0.1" color="red"></a-sphere> <!-- Protons -->
      <a-torus position="0 0 0" arc="360" radius="0.5" radius-tubular="0.01">
         <a-sphere position="0.5 0 0" radius="0.05" color="blue"></a-sphere> <!-- Electrons -->
      </a-torus>
    </a-entity>
  </a-nft>
</a-scene>

การนำไปสอน

ช่วยให้นักศึกษาสามารถมองเห็นชั้นพลังงาน (Shells) และการจัดเรียงตัวของอิเล็กตรอนในพื้นที่ 3 มิติ ซึ่งจะทำความเข้าใจได้ยากจากภาพ 2 มิติปกติ

2. 3D Vector Visualizer (Marker-based)

การใช้ Marker เพื่อกำหนดจุดอ้างอิง (Origin) แล้วให้ผู้เรียนลากเส้นเวกเตอร์ X, Y, Z โดยอาศัยมุมมองจากเบราว์เซอร์

[ 3D Visualization Placeholder: แกน X(แดง) Y(เขียว) Z(น้ำเงิน) พุ่งออกจาก Marker บนพื้นโต๊ะ ]

การแสดงผลแกนพิกัดฉาก

<a-marker preset="hiro">
  <!-- แกน X -->
  <a-entity line="start: 0 0 0; end: 1 0 0; color: red"></a-entity>
  <a-text value="X Axis" position="1.1 0 0" color="red"></a-text>
  
  <!-- แกน Y -->
  <a-entity line="start: 0 0 0; end: 0 1 0; color: green"></a-entity>
  
  <!-- แกน Z -->
  <a-entity line="start: 0 0 0; end: 0 0 1; color: blue"></a-entity>
</a-marker>

โจทย์คณิตศาสตร์สำหรับฟิสิกส์

โปรดลองคำนวณเวกเตอร์ผลลัพธ์ (Resultant Vector) จากแรงที่กระทำสองทิศทางบน Marker แล้วเขียนโค้ดเพื่อสร้างเส้นประแสดงการแตกเวกเตอร์
