Google Model-viewer

การแสดงผลอุปกรณ์การเกษตรแม่นยำสูงด้วยเทคโนโลยี Web Components และการปฏิสัมพันธ์ผ่าน Hotspots

1. Smart Irrigation Dashboard

การใช้โมเดล 3 มิติเป็นอินเทอร์เฟซหลัก (Dashboard) โดยการวาง Hotspots บนเซ็นเซอร์ต่างๆ เพื่อแสดงข้อมูลสภาพอากาศและความชื้นดินแบบ Real-time

[ 3D Visualization Placeholder: ชุดกล่องควบคุม IOT พร้อมป้ายดิจิทัลบอกค่า NPK และความชื้น ]

เทคนิคการจัดการ Hotspots

<model-viewer src="iot_node.glb" ar>
  <button slot="hotspot-temp" data-position="0.1 0.2 0">
    <span id="temp-display">28°C</span>
  </button>
</model-viewer>

<script>
  // อัปเดตข้อมูลจาก API ไปยัง Hotspot
  setInterval(() => {
    fetch('/api/greenhouse/temp')
      .then(r => r.json())
      .then(data => {
        document.getElementById('temp-display').textContent = data.val + '°C';
      });
  }, 5000);
</script>

ประโยชน์ในการเกษตรแม่นยำ

ช่วยให้เกษตรกรสามารถ "เดินสำรวจ" อุปกรณ์ผ่านมือถือในพื้นที่จริง (AR) และเห็นสถานะการทำงานของแต่ละส่วนประกอบได้ทันทีโดยไม่ต้องเปิดคอมพิวเตอร์

2. Drone Exploded View

การใช้ Animation Timeline หรือ Variants เพื่อแสดงส่วนประกอบภายในของโดรนพ่นยา (เช่น มอเตอร์, แบตเตอรี่, ถังน้ำยา)

[ 3D Visualization Placeholder: โดรนเกษตรที่ชิ้นส่วนแยกออกจากกันเพื่อแสดงโครงสร้างภายใน ]

การควบคุมแอนิเมชั่นด้วย UI

const mv = document.querySelector('model-viewer');

// เมื่อผู้ใช้คลิกปุ่ม "ดูโครงสร้างภายใน"
document.querySelector('#explode-btn').onclick = () => {
    mv.animationName = "ExplodeAction";
    mv.play();
};

// เมื่อต้องการซ่อน
document.querySelector('#assemble-btn').onclick = () => {
    mv.animationName = "AssembleAction";
    mv.play();
};

กรณีศึกษา: การซ่อมบำรุง (Maintenance)

นักศึกษาวิทยาลัยเกษตรสามารถใช้สมาร์ทโฟนส่องไปที่โดรนจริง แล้วกดดู Exploded View เพื่อระบุตำแหน่งของชิ้นส่วนที่ต้องเปลี่ยนหรือบำรุงรักษาอย่างถูกต้อง
