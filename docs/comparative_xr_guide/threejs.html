1. Projectile with Air Resistance

การจำลองการเคลื่อนที่แบบโพรเจกไทล์โดยคำนวณแรงต้านอากาศ (Drag Force) ซึ่งต้องใช้การรวมเชิงตัวเลข (Numerical Integration) แบบ Euler Method

[ 3D Visualization Placeholder: วิถีโพรเจกไทล์แบบโค้งพาราโบลาที่ซับซ้อน ]

ตรรกะทางคณิตศาสตร์ (Euler Method)

// คำนวณความเร่งจากแรงต้านอากาศ: a = (F_gravity + F_drag) / m
const drag = velocity.clone().multiplyScalar(-k * velocity.length());
const acceleration = gravity.clone().add(drag.divideScalar(mass));

// อัปเดตความเร็วและตำแหน่ง (Numerical Step)
velocity.add(acceleration.multiplyScalar(dt));
position.add(velocity.clone().multiplyScalar(dt));

2. Electric Field Lines

การแสดงผลเส้นแรงไฟฟ้าจากประจุจุด (Point Charges) โดยใช้ Three.js ArrowHelper เพื่อสร้างเวกเตอร์ฟิลด์ในพื้นที่ 3 มิติ

[ 3D Visualization Placeholder: เส้นแรงไฟฟ้าพุ่งออกจากประจุบวกไปยังประจุลบ ]

โค้ดการสร้าง Arrow Field

const direction = new THREE.Vector3();
const totalForce = new THREE.Vector3(0, 0, 0);

// คำนวณแรงลัพธ์จากทุกประจุที่ตำแหน่ง (x, y, z)
charges.forEach(q => {
    const distSq = pos.distanceToSquared(q.pos);
    const force = k * q.value / distSq;
    const vec = pos.clone().sub(q.pos).normalize().multiplyScalar(force);
    totalForce.add(vec);
});

// สร้างลูกศรเวกเตอร์
const arrow = new THREE.ArrowHelper(totalForce.clone().normalize(), pos, totalForce.length(), 0xff6b00);
scene.add(arrow);
